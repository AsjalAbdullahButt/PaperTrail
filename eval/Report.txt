1. WHAT THIS SYSTEM IS
-------------------------------------------------------------------------------
PaperTrail answers natural-language questions over a fixed corpus of NLP
research papers and cites the exact passages its answer rests on. Pipeline:

  load -> chunk -> embed -> retrieve -> [re-rank] -> generate -> [fact-check]

with optional stages (each a per-query switch in the web app, off by default):
  - cross-encoder RE-RANKING of the hybrid top-20
  - HyDE QUERY EXPANSION (an LLM writes a hypothetical answer passage)
  - NLI GROUNDING (every answer sentence checked for entailment)
  - ABSTENTION (decline to answer when retrieval confidence is low)
  - CONTEXTUAL CHUNK HEADERS ("<paper title> | <section>" embedded with each chunk)

The evaluation imports the production modules directly (ingestion.py, llm.py,
similarity.py, services/bm25_index.py, importance.py, retriever.py, reranker.py,
nli_guard.py, abstention.py, query_expansion.py): it measures the same code the
live app runs, not a reimplementation of it (one documented exception: the
hybrid SCORING is re-implemented because the production function needs a
database session; its weights and normaliser are imported).

No models were trained or fine-tuned. All models are pretrained and used as-is,
per the course rules ("Do not train models from scratch").

Qualitative takeaways (see REPORT.md section 6.7 for the reasoning):
  - Hybrid never hurt and usually helped DOCUMENT recall; the dense->hybrid
    changes in evidence recall are positive-leaning but mostly within noise.
  - BGE-small beat MiniLM on most (not all) pairs; BM25 fusion narrows the gap.
  - Most of the "sentence chunking is better" effect is CHUNK SIZE, not
    boundary alignment: it shrinks when size is held constant (6.3 vs 6.4).
  - Re-ranking raises passage precision (evidence recall, MRR, section hit)
    but can lower document coverage on multi-hop questions: a real trade-off.
  - Contextual chunk headers: no reliable benefit (honest null result).
  - HyDE: the largest retrieval gain, BUT the LLM has largely memorised these
    famous papers, so the gain here overstates what a private collection gives.
  - Doc Recall@5 is far above Evidence Recall@5 in every configuration: the
    right paper is usually found, the right passage often is not.

Sanity checks on the metrics themselves:
[[BEGIN:sanity]]
  - LLM-judge abstention verdict agrees with a regex abstention heuristic on 95% of 184 answers.
  - Pearson correlation between the hallucination guard's unsupported-sentence rate and the judge's
    faithfulness score: -0.13 (n=152). A strongly negative value means the lexical guard tracks the
    judge; the guard is a heuristic, not a proof of grounding.
[[END:sanity]]

Qualitative takeaways (REPORT.md section 5.3):
  - Answer quality tracks retrieval quality: dense -> hybrid raised judged
    correctness and (significantly) faithfulness on the paired configuration.
  - Cross-encoder re-ranking did NOT change judged answer quality, although it
    improved passage-level retrieval: five passages in the prompt were already
    enough evidence for the generator.
  - Citation accuracy stays below 50% in every scored configuration: most [n]
    markers point at a passage without the gold quote even when the answer is
    right. This is the largest remaining weakness.
  - The HyDE configuration is retrieval-scored only (free-tier token limit).

How to read these honestly:
  - Citation accuracy is the fraction of CITED passages that contain the gold
    evidence; a correct answer can still cite the wrong passage.
  - Single judge model per run, n ~ 38 answerable questions: correctness CIs
    span about a point on the 1-5 scale. Compare configurations only through
    the paired intervals, never through point estimates alone.
  - The generator and judge are different models of the same family.

Qualitative takeaways (REPORT.md section 7):
  - Abstention: the top dense cosine separates answerable from unanswerable
    questions well for the BGE configurations, the re-ranker probability gives
    a model-independent signal, and the hybrid fused score is useless (it is
    normalised per query). A calibrated threshold MATCHES the generator's own
    abstention rather than beating it; its value is that it skips the LLM call
    and is explicit and tunable. Only 8 unanswerable questions: wide intervals.
  - NLI grounding is a NEGATIVE result: the small off-the-shelf NLI model flags
    over half of all answer sentences as unsupported (it handles numerals and
    technical paraphrase poorly) and does not track the judge, whereas the
    lexical heuristic correlates modestly. NLI is therefore an experimental,
    opt-in switch; the lexical guard remains the default.
  - Judge reliability: two judges from different model families agree closely
    on correctness. Agreement with a HUMAN is pending (human column is blank).
  - Failure taxonomy: outright wrong answers are a minority; the biggest
    defects are correct answers with citations pointing at the wrong passage,
    then needless refusals to answer.

10. THE WEB APPLICATION  (what a user can do with all of this)
-------------------------------------------------------------------------------
Under the query box, an "NLP pipeline" bar has four switches (disabled, with
the reason, when the server cannot run them): Re-rank, HyDE, NLI grounding,
Abstain if unsure. The answer shows badges for the stages that actually ran
(and any fallback note); each source card shows Dense / BM25 / Importance /
Re-rank score chips; a "Claim-by-claim grounding" panel lists each answer
sentence with its entailment % and links it to the supporting source card; an
amber banner explains an abstention while still listing the retrieved passages.
API: GET /api/query/capabilities; POST /api/query and /api/query/stream accept
"options" and return abstained, grounding, pipeline and per-source score fields.

12. LIMITATIONS (state these honestly in the presentation)
-------------------------------------------------------------------------------
  - Answer quality is scored for only some configurations (section 7); the
    retrieval conclusions (5-6) cover all of them. The advanced arms were
    evaluated mainly on retrieval metrics.
  - 46 questions / 14 papers: patterns, not tight intervals. Abstention
    calibration rests on only 8 unanswerable questions; thresholds are
    specific to the embedding model and must be re-calibrated elsewhere.
  - HyDE's gain is inflated by the LLM having memorised these famous papers.
  - Generator and judge share a model family; the human column in 8.3 and
    section 11 is provided but must be filled by a person.
  - Evidence matching is textual, so Evidence Recall is conservative; section
    labels come from heuristic heading detection.
  - Embeddings evaluated are two local Hugging Face models; the production
    default (OpenAI text-embedding-3-small) was not benchmarked (no key).
  - The lexical hallucination guard is a HEURISTIC, not a proof of grounding;
    section 8.2 measures how it compares with NLI.
